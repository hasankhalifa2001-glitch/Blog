# Next.js Blog with Prisma

مشروع مدونة شخصية مبني باستخدام Next.js مع Prisma لإدارة قاعدة البيانات بطريقة سهلة وفعالة.

---

## 📌 نظرة عامة

- **الإطار المستخدم:** Next.js (React framework)
- **قاعدة البيانات:** PostgreSQL / MySQL / SQLite (أي واحد تستخدمه مع Prisma)
- **ORM:** Prisma
- **الهدف:** إنشاء مدونة مع واجهة مستخدم جميلة مع إدارة ديناميكية للمقالات من قاعدة البيانات.
